# Documentation de la configuration NixOS

Bienvenue dans la documentation du dépôt `llafon-analytics/nixos` : la configuration NixOS (flake)
des machines `desktop` et `laptop`.

## Ce que vous trouverez ici

- **Architecture** : flake, modules, arborescence.
- **Hosts** : différences entre `desktop` et `laptop`, ajout d'un nouveau host.
- **Modules** : système, Home Manager, paquets, overlays, GPU, Hyprland, Caelestia, Stylix.
- **Opérations** : rebuild, mise à jour de la flake, rollback, dépannage, Tailscale.
- **Développement** : checks, CI, conventions, agents IA, documentation.
- **Référence** : aliases, ports, groupes de paquets, inputs, fix temporaires.

## Portée

Cette documentation décrit uniquement les éléments présents dans le dépôt.
