# Adding a host

## 1) Create the host directory

```text
hosts/<host>/
├── default.nix     # system
├── hardware.nix    # generated by nixos-generate-config
├── home.nix        # the user's Home Manager configuration
└── hyprland.lua    # host monitors, input, binds
```

Generate `hardware.nix` on the target machine:

```sh
nixos-generate-config --show-hardware-config > hosts/<host>/hardware.nix
```

## 2) `default.nix`

```nix
{ ... }:

{
  imports = [
    ./hardware.nix
    ../../modules/nixos
    ../../modules/nixos/hardware/amdgpu.nix   # or nvidia.nix
  ];

  networking.hostName = "<host>";

  users.users.<user> = {
    isNormalUser = true;
    extraGroups = [ "networkmanager" "wheel" "video" "input" ];
  };
  home-manager.users.<user> = import ./home.nix;
  nix.settings.trusted-users = [ "<user>" ];

  # Ports are only opened on Tailscale.
  networking.firewall.interfaces.tailscale0.allowedTCPPorts = [ ];

  system.stateVersion = "26.05"; # release of the first installation
}
```

## 3) `home.nix`

```nix
{ ... }:

{
  imports = [ ../../modules/home/common.nix ];

  home.username = "<user>";
  home.homeDirectory = "/home/<user>";
  xdg.configFile."hypr/host.lua".source = ./hyprland.lua;
}
```

## 4) Declare the host

In `flake/hosts.nix`:

```nix
<host> = mkHost { name = "<host>"; };
```

## 5) Check

```sh
git add hosts/<host>       # the flake only sees files tracked by git
nix eval --raw .#nixosConfigurations.<host>.config.system.build.toplevel.drvPath
nix flake check --no-build
```
