# Home Manager

## Layout

- `modules/nixos/home-manager.nix`: NixOS integration (`useGlobalPkgs = true`,
  `useUserPackages = true`, `.backup` file extension, Zen and Caelestia HM modules).
- `modules/home/common.nix`: everything both users share; it imports `caelestia.nix`,
  `zen-browser.nix`, `vscode.nix`, `zsh.nix`, `cli-tools.nix` (Atuin, zoxide, Lazygit, nh),
  `pyprland.nix`, `neovim.nix`, `fastfetch.nix` and `hyprland/`.
- `hosts/<host>/home.nix`: what differs per host.

Home Manager uses the system package set: same overlays, same `allowUnfree` and, on the desktop,
the same `cudaSupport` (see the `obs-backgroundremoval-cpu` temporary fix).

## Deployed files

`modules/home/common.nix` links from `dotfiles/`: Doom Emacs config, btop themes, YouTube Music CSS,
`hyprlock`, the wallpaper (`Pictures/Wallpapers`, read by Caelestia) and `coc.lua` for Neovim. It
also installs the `temp-fixes` command.

Caelestia's configuration (`~/.config/caelestia/{shell,cli}.json`) is generated by its module.

## Main differences

| Topic | desktop | laptop |
|---|---|---|
| Specific packages | OBS Studio (CUDA) + plugins, lazydocker | `moonlight-qt` (unstable) |
| zsh aliases | `valheim` | `ac`, `bat` |
| Git signing | not enforced | `signing.format = openpgp` |
| rofi | repository Catppuccin theme | Stylix theme |
| YouTube Music config | `config-desktop.json` | `config.json` |
